# NuclearGrid

Nuclear power plant simulation plugin for Paper servers.

## Download

Download the latest `.jar` from the [GitHub Releases page](https://github.com/wolf3five99/NuclearGrid/releases).

> Releases are the official download location. This repository intentionally does not include Java source files.

## Installation

1. Download the NuclearGrid `.jar` from Releases.
2. Stop your Paper server.
3. Place the `.jar` file in your server's `plugins/` directory.
4. Start the server and check the console for plugin errors.

Use a server version compatible with the specific release. Back up your world before testing plugins that can alter blocks or simulate reactor incidents.
